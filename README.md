

\# Student Course API



A REST API built using Node.js and Express.



\## API Endpoints



\- GET /api/health

\- GET /api/courses

\- GET /api/courses/1

\- GET /api/courses/9999



\## Installation



1\. Install Node.js.

2\. Open the project folder in the terminal.

3\. Run npm install.

4\. Run npm start.



\## Local Server



http://localhost:3000/api/health



\## Deployment



This backend can be deployed using Render.



Build Command: npm install



Start Command: npm start



Health Check Path: /api/health
